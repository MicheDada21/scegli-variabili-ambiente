# variabili-ambiente-vercel-convex

Decide se una variabile d'ambiente va su Vercel, su Convex o su entrambi in base a dove il codice la legge.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [Scegli dove mettere le variabili d'ambiente](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/variabili-ambiente-vercel-convex). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install variabili-ambiente-vercel-convex@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install variabili-ambiente-vercel-convex@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Per avere tutte le skill della libreria installa `tutte-le-skill@ch-labs-skills`. Con altri agenti copia la cartella `skills/variabili-ambiente-vercel-convex` tra le skill dell'agente, per esempio in `~/.codex/skills/variabili-ambiente-vercel-convex`.
